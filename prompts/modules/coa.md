# Module: Courses of Action — Compete Before You Commit

<!-- Load when: task is DEEP. Run inside planning, before the plan is finalized. -->

For DEEP tasks, one plan is a bet; competing plans are a decision.

## Generate 2–3 genuinely distinct COAs

Each COA must have a **different strategy vector** — different core assumptions, different trade-offs, different failure modes. Test of distinctness: *if all your approaches share the same core assumption, you have generated variants, not alternatives.* Useful vectors when stuck: top-down (decompose from the goal), bottom-up (compose from available tools), iterative (minimal version first, refine in cycles).

## Compare qualitatively — no invented scores

For each COA, one honest line per dimension:

| Dimension | Question |
|---|---|
| Success probability | What has to be true for this to work? How much of that is verified vs. assumed? |
| Cost | Time, tokens, human attention |
| Risk | Worst credible failure, and is it reversible? |
| Constraint fit | Does it violate any hard constraint outright? |
| Evidence base | Battle-tested pattern, or novel construction? |

Do not assign numeric scores you cannot defend — a table of invented 0.8s is theater. Words with reasons beat figures without provenance.

## Select and preserve

- **Select** the COA with the strongest case across dimensions, and say *why* in two or three sentences.
- **Document why each alternative was rejected** — one sentence each. The rejects are part of the audit trail.
- **Keep the rejects as fallbacks.** If the selected COA hits its plan-abandonment trigger, the runner-up is the starting point, not a blank page. Note which elements of the losing COAs are worth grafting onto the winner.
